# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) by reference. The full text is available at that link and applies to every space where the project is discussed: issues, pull requests and discussions.

In short:

- Be respectful and patient, especially with newcomers.
- Give and accept feedback about the work, not the person.
- No harassment, discrimination or personal attacks.
- Never share other people's personal data, or course materials you are not allowed to share.

## Enforcement

Report conduct problems privately to the repository owner, [@alethegoat](https://github.com/alethegoat), through GitHub (for example by contacting them from their profile). The owner may edit or remove comments, close issues and pull requests, or block users who break these rules.

This is a volunteer student project, so responses are best effort.
